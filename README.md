# AI Tutoring

Площадка для экспериментов с MCP-серверами и навыками, создания дашбордов и наглядных материалов для учеников.

Работающие дашборды: [каталог GitHub Pages](https://Plat01.github.io/ai-tutoring/).

- [Азбука ИИ: от чата до агента](https://Plat01.github.io/ai-tutoring/dashboards/ai-basics/) — 41 понятие, различия, официальные источники и упражнения для взрослого новичка.

Порядок публикации: [GitHub Pages](docs/github-pages.md).

## Каталоги

- `experiments/` — эксперименты с MCP и навыками.
- `dashboards/` — учебные HTML-дашборды и их ресурсы.
- `materials/` — остальные учебные материалы.
- `data/` — исходные данные и описание их происхождения.
- `docs/` — документация по инструментам и работе с проектом.

## Lavish

Подробная инструкция: [Работа с Lavish](docs/lavish.md).

Дашборды в этом проекте создаём и просматриваем с помощью [lavish-axi](https://github.com/kunchenguid/lavish-axi). CLI установлен как локальная зависимость проекта; навык находится в `.agents/skills/lavish/SKILL.md`.

Требуется Node.js 22 или новее. Для восстановления зависимостей:

```bash
npm ci
```

Сохраняй каждый дашборд в `dashboards/<название>/index.html`, а локальные ресурсы — рядом с HTML, используя относительные ссылки. Открыть готовый дашборд в Lavish:

```bash
npm run lavish -- dashboards/<название>/index.html
```

Справка и актуальные рекомендации по созданию материалов:

```bash
npm run lavish -- --help
npm run lavish -- design
npm run lavish -- playbook
```

Lavish позволяет просматривать HTML в браузере, оставлять замечания к элементам страницы и передавать их агенту. Сам HTML можно открыть и непосредственно в браузере.

Установка локальная: глобальные настройки, хуки и MCP-конфигурация не изменяются. Навык будет доступен Codex со следующего хода; правило использования Lavish закреплено в `AGENTS.md`.
