# Проверка справочника

Дата: 12 октября 2026 года.

Проверено в Chromium через Playwright: локальный просмотр в Lavish и самостоятельная статическая страница, подготовленная для GitHub Pages.

- 40 карточек; у каждой есть официальные источники. Все ссылки на внутренние термины ведут на существующие элементы.
- 32 уникальные страницы документации отвечают HTTP 200; результаты — `sources-check.json`.
- Поиск MCP, фильтр интерфейсов (9 карточек), пустой поиск, сброс фильтров и переход к скрытому термину работают.
- Все 8 сравнений показывают по 3 соответствующие колонки.
- Bash, PowerShell и cmd показывают разные команды; переход в materials и обратно меняет условную CWD. Список файлов соответствует выбранной учебной папке.
- Модель контекста: исходное заполнение 800 из 1 000; максимальное — 1 450, превышение 450. Сокращение истории 650 → 250 даёт 1 050; повторное сокращение до 100 даёт 900. Переполнение не скрывается, одного сокращения не всегда достаточно.
- Все 6 правильных ответов дают результат 6 из 6; изменение ответа корректно меняет счёт; сброс работает.
- Визуально просмотрены тёмная и светлая темы, SVG, карточки и упражнения. Проверены ширины 1280 и 390 px; горизонтального переполнения нет. Основная кнопка имеет явные цвета фона и текста в обеих темах.
- На самостоятельной странице нет ошибок JavaScript. Внешние библиотеки не загружаются из сети: CSS и JS находятся локально.
- Сборка `node scripts/build-pages.mjs` успешно создаёт `_site/`; каталог ведёт на дашборд с сохранением относительных путей ресурсов.
- `node --check` для двух JS-файлов дашборда и скрипта подготовки сайта, `git diff --check` проходят.

Особенности проверки: при первом подключении тестового браузера к Lavish сервер один раз вернул HTTP 409 для устаревшей ревизии iframe, затем загрузил актуальную. Это не воспроизводится на самостоятельной странице. HTTP-проверка некоторых источников потребовала повторного запроса без Brotli из-за ошибки декодирования в Python requests; повторные запросы прошли.

Скриншоты использованы для локальной визуальной проверки; в опубликованный сайт служебные отчёты и скриншоты не включаются.
