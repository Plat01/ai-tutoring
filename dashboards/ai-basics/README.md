# Азбука ИИ: от чата до агента

Учебная цель: взрослый новичок различает приложение, модель и агента; понимает роль интерфейса, файлов, контекста и подключений; читает простые инструкции по работе с ИИ.

## Что создано

- 41 понятие с русскими и английскими названиями, примерами, различиями и официальными ссылками. Модель ИИ и GPT объяснены отдельно.
- 8 сравнений близких терминов.
- Учебная консоль с переключением Bash / PowerShell / cmd.
- Условная схема контекстного окна и 6 вопросов для самопроверки.
- Светлая и тёмная темы, мобильная вёрстка.

## Открыть

Из корня проекта:

```bash
npm run lavish -- dashboards/ai-basics/index.html
```

Основной способ доступа — работающая страница в GitHub Pages (настройка публикации описана в `docs/github-pages.md`). Для локального просмотра можно открыть `index.html` непосредственно в браузере; интернет нужен только для перехода к документации.

## Исходники и зависимости

- `index.html` — структура страницы и SVG-иллюстрации.
- `assets/content.js` — авторские объяснения, список источников, сравнения и вопросы.
- `assets/app.js` — поиск, фильтры и учебные взаимодействия.
- `assets/style.css` — вёрстка, адаптивность и темы.
- `assets/vendor/` — локальные копии DaisyUI 5.5.19, тем и Tailwind browser 4.2.4, полученные по URL из `lavish design`. Их происхождение: jsDelivr, пакеты `daisyui` и `@tailwindcss/browser`; лицензии MIT. Для работы страницы Node.js не нужен.
- Для просмотра в Lavish: установленный в проекте `lavish-axi` 0.1.87; зависимости восстанавливаются `npm ci`, нужен Node.js 22+.

У дашборда нет отдельной сборки. После редактирования исходников обновите локальную страницу и опубликуйте изменения в GitHub Pages.

## Источники и допущения

Официальная документация OpenAI, MCP, Microsoft, Ubuntu, Python, Git и VS Code; MDN для веб-понятий. Ссылки находятся рядом с объяснениями; полный перечень — объект `SOURCES` в `assets/content.js`. Дата проверки: **12 октября 2026 года**. Статусы и конечные адреса проверенных страниц — `sources-check.json`.

Определения пересказаны своими словами. Это вводный материал, а не описание всех реализаций. Названия интерфейсов, доступность функций, размеры окон и наборы уровней reasoning effort зависят от продукта и модели. Намеренно не зафиксированы цены, лимиты конкретных тарифов и «самая новая модель».

Консоль полностью демонстрационная: вывод подготовлен заранее, команды не выполняются, файлы и пути вымышленные. В схеме контекста ёмкость 1 000 токенов и остальные числа условные; это не токенизатор, калькулятор стоимости или фактический лимит модели. Аналогия со столом и шкафом иллюстрирует понятия, но не архитектуру модели.

Ответы на вопросы живут только в памяти страницы до перезагрузки. Страница не обращается к API, не собирает персональные данные и не содержит ключей доступа.
